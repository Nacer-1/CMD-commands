# CMD-commands

A collection of useful CMD commands, Windows tips and handy command-line tools to simplify everyday tasks.

/* Command Update all Windows apps with one command every installed app at once */

`winget upgrade --all`

/* How to use */

1. Press `Win + S`, type `cmd`.
2. Right-click **Command Prompt** and choose **Run as administrator**.
3. Paste the command and press `Enter`.
